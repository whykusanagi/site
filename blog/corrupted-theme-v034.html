Release Notes

Corrupted Theme 0.3.4: a whole page from one stylesheet

Published 8 October 2026 · editorial.css grows from an article frame into a complete page vocabulary.

TL;DR

  • A whole page, not just an article. Cards, ranked tables, meters, chart frames, legends, galleries, post index and post chrome all ship in the theme now. A site using this can delete its own post-content stylesheet.
  • +3.6 KB gzipped (+19.4 KB minified) for the lot.
  • Nothing public was renamed. Three card-ish classes collapsed into one .ct-card, and four label classes into .ct-label — but those names had never shipped, so the consolidation cost nobody a migration.
  • Stylesheets describe themselves to agents now. manifest.json lists a CSS export's classes, modifiers and custom properties, so an LLM can use the vocabulary without fetching the sheet.

The problem this solves

Every site I run ends up writing the same CSS twice. The theme handled the chrome — navbars, glass panels, buttons — and then each site wrote its own stylesheet for the thing people actually read: the post body, the stat tiles, the ranked table, the pull quote.

0.3.4 moves that second stylesheet into the package. The recap page above is one HTML file and one <link>. No bespoke CSS, no utility framework underneath.

What's in the box

  • Cards and figures: one .ct-card shape with a corner tick, a raised variant, labels, big values and change deltas.
  • Data display: ruled rows, meters, chart frames, legends, and tables that scroll sideways on a phone instead of pushing the page wider.
  • A six-step rank scale in two colour maps — a standard scale, and .ct-ranks-corrupted that switches the whole thing to the theme palette. Every rank ink is checked for WCAG AA contrast against the surface it actually sits on, not against a convenient one.
  • Post chrome: post index cards, previous/next navigation, and a footer block.

Six corruption patterns are now defined in the spec, and the machine-readable surface finally says so — it had been claiming four since Pattern 5 shipped.

The endpoint has to stay readable

The aesthetic rule this package has always had is that corruption is a transition, not a destination. Text decodes out of noise and settles somewhere you can read.

0.3.4 fixes a case where that wasn't true. If you hid a browser tab while a heading was mid-decode, the animation stopped and the heading stayed frozen on scrambled glyphs — permanently. Stopping a decode now settles the element on its final text, which is what the rule said all along.

Two other things in the same spirit: a muted card used to dim its own labels below the contrast floor, and MicroGfx now ships fitTitle(), so a long card title shrinks to fit instead of running off the edge.

Upgrading

Additive — no export was removed or renamed, so a version bump is the whole migration.

  • CDN: https://cdn.whykusanagi.xyz/corrupted-theme/@0.3.4/dist/theme.min.css (also on cdn.nikkers.cc; @latest resolves to 0.3.4)
  • npm: npm install @whykusanagi/corrupted-theme@0.3.4

SHA-384 integrity hashes for every loadable artifact are in the changelog, and the live demo is the page in the screenshots above.

Ask Celeste

Q: I'm pinned to 0.3.3 and I vendored a couple of files. Will this break me?
A: No. Nothing was removed or renamed from the public API, and @0.3.3 on the CDN is immutable — it keeps serving exactly what it served yesterday. The only files that disappeared in 0.3.4 were two that were never in the package's exports map and never documented as importable, so nothing you could legally import is gone.

Q: Do I have to use the editorial classes to get the update?
A: No, and that's the point of the gzipped number. editorial.css is bundled but inert — it's class-scoped, so nothing changes until you write ct- on an element. If you only want the navbar and glass panels, you still only get the navbar and glass panels.

Q: Why does the agent surface matter for a CSS package?
A: Because half the sites using this are maintained by an LLM reading manifest.json. Before 0.3.4 a stylesheet export was one line that said "this is CSS", which is useless — the agent had to fetch and parse the sheet, or guess. Now the export carries its class list, its is-*/has-* modifiers and every custom property with its default. An agent can build a page from the manifest alone.
